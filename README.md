# Cynthia J. Giachino — Author Website

Single-page author site. The approved design is `materials/layout.png`; the
implementation lives in `site/`.

- **`site/`** — React 18 + Vite + TypeScript + Tailwind app. See `site/README.md`
  for the asset map, sampled palette, font choices, and run instructions.
- **`materials/`** — source imagery and the approved layout comp.

## Quick start
```bash
cd site
npm install
npm run dev
```
